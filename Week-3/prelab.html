2. CSS Code to Apply Styles to Tab

HTML Code

<!DOCTYPE html>
<html>
<head>
    <title>Tab Example</title>
    <link rel="stylesheet" href="style.css">
</head>

<body>

    <div class="tab">
        <button class="tab-button">Home</button>
        <button class="tab-button">About</button>
        <button class="tab-button">Contact</button>
    </div>

    <div class="tab-content">
        <h2>Welcome</h2>
        <p>This is a simple tab styled using external CSS.</p>
    </div>

</body>
</html>

External CSS Code — style.css

body {
    font-family: Arial, sans-serif;
    background-color: #f2f2f2;
}

.tab {
    max-width: 700px;
    margin: 20px auto;
    border: 1px solid #ccc;
    background-color: white;
    overflow: hidden;
}

.tab-button {
    background-color: #4CAF50;
    color: white;
    border: none;
    padding: 12px 20px;
    cursor: pointer;
    float: left;
}

.tab-button:hover {
    background-color: #45a049;
}

.tab-content {
    max-width: 700px;
    margin: 0 auto;
    padding: 20px;
    background-color: white;
    border: 1px solid #ccc;
    box-sizing: border-box;
}
